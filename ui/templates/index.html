Cost per request is tokens used times the unit price. A request that bills 10 prompt and 16 completion tokens costs 10 × prompt rate + 16 × completion rate.

Budgets (cut-off point)

A subject can use its grant until it runs out. Setting a budget replaces the grant; the entitlement reports hasAccess: false once usage passes it. Token budgets cut off on tokens; a USD budget cuts off on dollars, because that entitlement meters the priced cost of each request.

Budget enforcement

The gateway asks the metering relay for the subject's balance before every call. With enforcement on, an exhausted budget makes that answer hasAccess: false and the gateway returns HTTP 429. With it off, the relay answers "allowed" and traffic keeps flowing while usage is still metered and shown above.

Subscriptions

    Changing a price creates the next plan version, publishes it and moves active subscriptions onto it with immediate timing. Usage already recorded is not re-priced.
